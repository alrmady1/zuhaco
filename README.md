# شركة زهى الاعمال للمقاولات

نظام إدارة مشاريع ومقاولات: عروض أسعار، عملاء، مهام مشرفين، محاسبة، عقود، وصلاحيات حسب المسمى الوظيفي.

موقع ثابت (HTML/CSS/JS) بدون خادم أو قاعدة بيانات؛ البيانات تُخزّن محلياً في متصفح كل مستخدم عبر `localStorage`.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح أو شغّل خادماً بسيطاً من جذر المشروع:

```bash
npx serve .
```

## النشر على Vercel

المشروع ثابت بالكامل (لا يحتاج خطوة بناء)، لذا يكفي ربط مستودع Git الخاص به بمشروع جديد على Vercel واختيار "Other" كإطار العمل — سينشر Vercel الملفات كما هي.
